# EMERGENCE — Smart Emergency Management System

## Overview

EMERGENCE is a modular emergency management system developed using Java, JDBC, MySQL, HTML, CSS, and JavaScript. The system allows users to manage emergency contacts, trigger emergency alerts, and monitor alert activity through an interactive dashboard.

---

## Features

- User Registration & Login
- Emergency Alert Triggering
- Emergency Contact Management
- Dynamic Dashboard UI
- Alert History Tracking
- JDBC-MySQL Integration
- DAO & Service Layer Architecture
